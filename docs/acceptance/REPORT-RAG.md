# 本地向量RAG验收

执行日期：2026-10-03，中国时间。承接青禾v0.3，新增实际中文嵌入与向量检索，保持已有MySQL政策原文、业务记录和回答模型设置。

## 最终实现

- FastEmbed 0.8.1加载`BAAI/bge-small-zh-v1.5`，在本机CPU生成512维中文向量。
- Qdrant Client 1.19.1本地持久化存储；14份核验资料生成155个片段，每片最多320字符、重叠64字符，并保留原文字符范围。
- 学校/国家、用途、年份和时效过滤先于向量检索；资料撤销与元数据变化按当前SQL生效。条号查询继续准确定位。
- 关键词和语义排名使用RRF融合，问题适配统一领域上下文；不存在依据的学校工资和历史招聘保持拒答。
- 内容指纹识别资料变化；新collection完成后原子切换，失败回退当前关键词原文；请求时不下载模型。
- 管理员可查看模型、资料数量、片段数量和构建时间，刷新状态、重建索引；普通角色不能调用管理接口。
- 回答展示本轮检索方式并保留出处。政策数字校验增加周期与比较关系检查；动态工具和预取工具共用字段脱敏流程。

## 在线样例与限制

最终保存的3道在线样例在临时SQLite中导入同一套核验原文，使用真实本地BGE和本机既有MiMo配置。两个有依据问题生成model回答：每礼拜排班命中S08第二十一条；工作前带教命中S08第十八条并引用。学校时薪仍无可靠依据，采用original_query显示边界。结果包含候选文本与最终文本，便于分析后续校验降级。

开发中发现重复领域前缀会使培训问题更偏向总则，已统一检索上下文并验证培训条款能召回。在线生成仍有随机性，一次成功不能说明总体稳定性。周/月数字反例已有回归，但校验仍不是完整逐句事实核验。

本轮未修改申请、岗位、工时和计薪记录；管理员索引重建产生正常审计，页面提问追加一条演示对话。项目已有同日工时累计、岗位卡片条件收紧等审查问题仍待后续处理。

Qdrant本地目录只支持当前单进程部署；扩展多worker需使用独立Qdrant服务。模型未下载、索引不可用或库锁冲突时明确降级。学校现行完整细则与具体酬金缺口保持原有边界。
