## Windows 启动与复位

1. 发现 SQLite 备份 `with connection` 不会关闭连接，Windows 无法删除源数据库。已改为 `contextlib.closing`，临时库回归和真实复位通过。
2. Windows 虚拟环境 Python 会转交给基础解释器子进程。归属识别加入直接父进程校验，启动参数显式带项目 `--app-dir`。按路径边界检查，并保留 PID/启动时间确认。
3. 实测“重复启动 → 停止 → 重新启动 → 再次重复启动”：成功；重复启动的两个 PID 和启动时间保持相同，没有生成重复服务。
4. 复位只允许项目内 `data/campus_demo.db`、demo 环境及确认标识，先创建可读备份，再恢复种子；不会重置 MySQL 或其他路径。
5. 服务只监听 127.0.0.1:5173 / 8000，后台隐藏启动。通过本项目 manifest 控制停止，身份不匹配时拒绝操作并保留 manifest。
