# 青禾界面规范

ui-ux-pro-max 已用于设计推荐，针对校园服务取暖色中性背景和深青绿主色。

- 背景 #f7f8f5；表面 #fff；主色 #17483d；强调 #df794e；正文 #253c35。
- 本地 Segoe UI / Microsoft YaHei，无远程字体依赖。数值用 tabular-nums。
- 220px 桌面侧栏、统一页面留白、明确任务按钮和卡片；手机折叠菜单与单列卡片。
- SVG 图标统一 lucide，独立 SVG 校园插画；不把 emoji 当图标。
- 表单有 label；点击目标至少 44px；键盘 focus；150–200ms 反馈；尊重减少动态设置。
- 演示说明放在页脚/帮助，金额显示估算及待核；产品操作页面不暴露密钥与初始化凭据。
