# 已核验官方资料导入与问答边界

本资料包包含 14 条官方资料目录记录和 S13 官方图片附件。原始档案及清洁文本保持原有 SHA-256；导入内容取自清洁文本的“【原文】”部分，核验者整理的页首说明不会混入原文引句。

## 导入方法

在项目 `backend` 目录运行：

```powershell
uv run python ../scripts/import_verified_sources.py
```

此命令只预览、核对资料哈希，不连接业务库写数据。真正导入由部署维护者在停止本项目 8000 后端、保持专用 MySQL 13308 运行时执行：

```powershell
uv run python ../scripts/import_verified_sources.py --apply
```

脚本要求演示环境和项目专属 MySQL 身份一致，先保存完整 SQL 备份，再显式升级 schema 0003，最后在一个事务内导入。原国家 2018 年政策按同一官方 URL 复用原文档 ID；首次导入应新增 13 份、更新原国家政策 1 份，最终 14 份。重复导入会保持同一 ID，不重复创建政策和导入日志。

`docs/acceptance/knowledge-import.json` 保存实际执行结果、SQL 备份路径及哈希、受保护表的导入前后哈希。岗位、时薪、申请、工时、用户和对话记录不因资料导入而修改。此文件只在正式执行成功后生成，不能将预览结果当作已写入的证据。

## 如何提问

| 示例问题 | 可用依据与回答边界 |
| --- | --- |
| 武汉设计工程学院有没有勤工助学制度？ | S01 第十六条确认制度存在 |
| 我应该找哪个部门咨询？ | S02 核验时公开的经济资助中心及电话 |
| 学校勤工助学一小时多少钱？ | 本校具体时薪尚未确认，不能从 12 元或 24 元推定 |
| 勤工助学每周最多工作多久？ | S08 国家原则：每周 8 小时、每月 40 小时；保留寒暑假例外 |
| 武汉设计工程学院现在学生助理怎么报名？ | 不能引用已截止批次充当当前公告，当前公开批次尚未确认 |
| 2025 年学生助理有什么要求，现在能报名吗？ | 明确历史查询，引用 S03 当批次条件，标记截止时间 |
| 2019 年武汉设计工程学院困难等级怎么规定？ | S07 仅历史资料，不能当现行等级 |
| 湖北省武汉最低工资标准和适用区域是什么？ | S12/S13 劳动关系参考，附件第一档按“武汉市区”原文引用；24 元不是本校时薪 |
| 国家取消民政证明的规定是什么？ | S11 取消所指证明环节，改为书面承诺；不能解释为取消全部材料或审核 |

## 供 AI 工具使用

`retrieve_policy(db, question, previous=None, limit=5)` 只读取依据，不保存对话。返回 `answer`、`citations`、`notice`、`retrieval`、`boundaries`。上轮上下文必须来自同一已认证用户的同一会话；支持 ChatLog 或上一条题目字符串，重新读取当前资料，不将历史引用当成新的可信证据。

每条引用包含来源 URL、资料编号、发布者、版本/日期、截止状态、适用范围、使用限制、核验状态、原件/清洁文本哈希。S13 图片转录通过 `quote_source_url` 指向实际官方附件。`policy_document_data(doc, include_sections=False)` 提供与这些引用一致的政策列表/详情数据。

`current_answer_allowed` 是默认检索准入标记，不是“现行有效”或“本校实施细则”的结论。`archive_only` 及已截止资料只在明确年份、资料编号或历史意图时检索；劳动标准只在明确劳动最低工资问题时返回。学校制度事实与学校具体业务规则分别处理，缺失本校依据时不得补出数字、资格认定或审批结论。

现阶段这里提供的是带范围和时效控制的原文取证。模型接入、对话生成、业务工具调用由 AI 模块完成；此导入模块不声称已经实现向量检索或独立的大模型推理。

## 验证

新增测试使用一次性 SQLite/MySQL 数据库，覆盖原政策 ID 与历史记录保留、重复导入、档案篡改拒绝、非官方/越界路径拒绝、历史与当前分开检索、学校时薪/等级缺口、劳动标准边界、日期/时区处理、旧表 schema 0003 升级与唯一索引。正式数据库不用于这些测试。
