# 首版核心规格登记（2026-09-30）

依据用户提供的 v1.1 总计划实施本地体验版 v0.1。规则为原型演示约定，不代表学校制度。

- 角色：student/unit/aid/admin。注册只能产生待启用学生；管理员启用；困难代码由资助中心确认。单位读写限本单位，学生仅本人申请、工时与金额。角色、单位、困难字段不属于可改档案。
- 申请：pending_review→approved→onboard→finished；pending_review 可驳回；学生可撤销 pending_review/approved。仅第一次撤销可重申第二次；终态、重复动作、超额、非法流转为 409。
- 岗位：draft/published/closed；关闭原因 full/manual。占用=approved+onboard+finished。满额自动关，批准后撤销仅恢复 full，主动关闭不自动恢复；草稿且无申请才可删除。
- 事务：SQLite 写事务 BEGIN IMMEDIATE 串行化。MySQL 配置使用岗位行锁保护名额，学生行锁保护跨岗工时，链尾锁与 predecessor 唯一约束保护更正。MySQL 实机验收未实施。
- 工时：十进制两位；中国自然日、周一自然周、自然月。仅上岗登记；结束后仅更正；更正允许 0 且必须说明。只累计链尾；按日期、原始创建时间、原始 ID 排序；周 8/月 40 超限的整条记录待核。新链尾不继承核实。
- 计薪：批准冻结类型、工资、40 小时基准和规则版本。临时 H×R；固定 min(H,40)/40×M；待核=F(正常+待核)−F(正常)。Decimal，中间不舍入，汇总结束 ROUND_HALF_UP。
- 匹配：时间40/困难25/技能25/区域10。D1=0、D2=50、D3=100；A↔B↔C。技能规范化精确匹配；空列表有效，null 缺失。时段同日合并后按分钟交集计算；缺字段总分 null。排序原始总分、时间、发布时间倒序、ID正序。
- 受控词表：office（办公软件）、excel（表格处理）、python（Python）、writing（文字写作）、photography（摄影）、design（设计）、communication（沟通）、organization（活动组织）、s1/s2（黄金算例代号）。
- 工资和统计按申请/学生/自然月分组；单位统计仅本单位，但异常阈值基于学生跨所有单位累计。正常与待核分列。
- 业务拒绝不写成功审计；成功写入与审计同一事务。错误 JSON 统一 error/message/details；输入校验用 400。
- 首版政策为已核验原文检索。RAG、向量库及模型岗位助手未实施；不编造学校细则、模型结果或导师确认。
- 空库初始化与固定种子；演示库和 pytest 临时库隔离。重置只允许本项目的 SQLite 演示文件，并先备份。

## 首版环境调整

默认 SQLite，保留 SQLAlchemy/MySQL URL；不配置或修改用户现有 MySQL。双击启动用构建后的 Vue（5173）和 FastAPI（8000）。无公网部署。

## 外部待确认

学校细则/困难等级定义、10-25 答辩性质、导师与学校验收要求均待用户或导师确认。首版不将完整长期计划的录屏、独立审查和智能模块评测记为完成。
