# LangChain 技术口径对齐清单

更新：2026-10-04。本文是任务书、开题材料和答辩 PPT 的建议替换文字与核对清单；未修改任何正式 Word 或 PPT 文件。

## 可直接使用的技术表述

> 本系统采用 LangChain 编排受控的 RAG 与只读工具调用流程。FastAPI 在 LangChain 之外执行 JWT 身份认证、角色与资源范围校验、Pydantic 参数校验、政策适用范围/时效过滤和业务规则计算；政策语义检索使用 FastEmbed 的 BGE 中文嵌入模型与 Qdrant 本地向量库。政策事实统一展示已核验原文摘录和确定性边界，不将模型自由生成结论标为已验证；模型或索引异常时退回原文、关键词或规则结果。

实现对应关系：

| 材料概念 | 实际代码与边界 |
| --- | --- |
| LangChain 编排 | `backend/app/langchain_flow.py` 使用 `ChatPromptTemplate` 渲染已脱敏消息，`ChatOpenAI` 调用 OpenAI 兼容模型，绑定服务器生成的固定只读工具 schema。 |
| 工具执行 | `backend/app/agent.py` 是唯一实际执行点：工具白名单、Pydantic、当前用户、单位/对象范围和只读边界都在此复核。模型工具调用不是授权指令。 |
| 政策 RAG | `backend/app/policy.py` 先执行学校/国家范围、用途、历史资料、劳动标准隔离和时效过滤；精确条款号直接查 SQL 原文。 |
| 语义检索 | `backend/app/rag.py` 使用 FastEmbed + `BAAI/bge-small-zh-v1.5` + Qdrant，本地持久化、关键词与语义融合；SQL 原文和元数据权威，Qdrant 是可重建派生索引。 |
| 回答校验 | 固定/临时岗薪酬问法先检索已核验原文；本校酬金无可靠依据时明确显示资料缺口。政策回答展示原文摘录和确定性边界；模型执行声明只在模型回答阶段检查，岗位关闭状态须由本轮只读工具结果支持，确定性工具回答不进入该拦截器。 |

## 建议替换文字

| 使用位置 | 建议文字 |
| --- | --- |
| 任务书/开题“技术路线” | 采用 Vue + FastAPI + MySQL 的业务系统；AI 层以 LangChain 编排受控 RAG 与只读工具，BGE + Qdrant 完成政策语义检索。 |
| 架构图“AI 模块” | LangChain：提示词、OpenAI 兼容模型、固定只读工具描述；FastAPI：认证、权限、Schema、业务规则、输出校验。 |
| 答辩 PPT“检索链路” | SQL 权威原文/元数据 → 范围/时效/用途过滤 → BGE 向量与关键词融合 → Qdrant 派生索引 → 已核验原文摘录与确定性边界；LangChain 只组织非政策解释和固定只读工具意图。 |
| 答辩 PPT“安全边界” | 模型不能选择身份、直连 SQL 或执行写操作；所有工具参数、资源归属和业务规则由 FastAPI 复核；无可靠依据、模型异常和索引异常均明确降级。 |
| 数据与薪酬说明 | 账号和业务数据均为模拟数据；薪酬为规则计算的应结算估算，不代表真实发薪。 |

## 不应使用的说法

| 不准确表述 | 原因与替代 |
| --- | --- |
| “LangChain 自动保证权限” | 权限由 FastAPI 执行；应说明 LangChain 只编排模型与固定只读工具描述。 |
| “知识库自动学习/自动训练” | SQL 已核验原文是权威来源，Qdrant 可重建；应说明检索与引用，不称学习。 |
| “使用其他向量库” | 实际向量库是 Qdrant；材料只写当前实际使用的 Qdrant。 |
| “自主执行的可写 Agent” | 实际没有可写 Agent；模型工具请求仍由 FastAPI 二次验证并仅执行只读查询。 |
| “RAG/AI 准确率 100%” | 固定开发题集结果只说明该题集的检索验收，不能外推为通用准确率。 |
| “24 元/小时就是本校时薪” | 劳动最低工资资料不等于学校勤工助学酬金；本校现行具体时薪资料缺口必须如实说明。 |

## 题集指标的限定写法

固定开发题集共 21 题，其中 16 题有已核验依据、5 题为无依据或资料缺口场景。历史开发结果为混合检索 Recall@5 100%、Top-1 87.5%、拒答 5/5；应写成“固定开发题集检索验收结果”，不得写成通用 AI 准确率或未知问题保证。

## 答辩前核对

- 演示管理员状态页确认模型和 RAG 状态，不展示或复制 API 密钥。
- 展示一条带原文出处的正常回答、一条本校细则/时薪资料缺口拒答，以及一条模型或索引降级状态。
- 说明 Qdrant health check 会核对 collection、向量维度和实际点数与 manifest 片段数；上述检查或语义查询异常时显示不可用并使用关键词降级。不要声称能够检测任意底层存储损坏，管理员才能重建派生索引。
- 不将模拟岗位、模拟薪酬、历史招聘或劳动最低工资说成学校当前正式规则。
- 正式 Word/PPT 仅按本文件建议替换文字修改；每页最终表述须与当前代码和 `REPORT-LANGCHAIN.md` 的实际验收结果一致。
