# 青禾 · 校园勤工助学服务智能体 v0.3 · MySQL版

根据《校园勤工助学服务智能体总计划 v1.1》实现的本地体验系统。Vue 3 + Vite + Element Plus；FastAPI + SQLAlchemy + MySQL 8。原SQLite数据已经保留迁入MySQL。v0.3加入多角色 AI 对话、已核验政策检索、岗位/申请/工时工具调用和管理员模型切换。业务数据和账号均为模拟，学校具体规则与导师要求仍待确认。

## 直接体验

1. 双击本目录的 **启动体验.bat**。程序会启动后端和前端，并打开 http://127.0.0.1:5173。
2. 登录页选学生、用工单位、资助中心或管理员，再点击“进入我的工作台”。账号和演示密码会填好。
3. 右上角头像菜单可以切换演示身份。数据会保存，退出或刷新不会丢失。

当前电脑已安装依赖并生成前端构建，MySQL已配置。启动脚本自动启动本项目MySQL（13308）、后端（8000）和前端（5173）。后台进程不弹额外窗口，应用日志在work/runtime；数据库目录以私有.env的MYSQL_RUNTIME_DIR为准。只绑定本机127.0.0.1。具体备份、配置和回退步骤见[MySQL使用说明](docs/MYSQL.md)。

## 建议先这样试

1. **学生**：发现岗位 → 搜索“文献数字化” → 详情 → 填理由 → 提交。我的申请显示待审核。
2. **单位 / 图书馆**：申请审核 → 找林同学的新申请 → 批准 → 确认上岗。
3. **单位 / 图书馆**：工时与薪酬 → 登记工时 → 选择这条申请，日期用今天，填1.5小时。冻结时薪22元时，正常估算增加33元。
4. **学生**：工时与薪酬查看本人新增记录；“我的申请”可看冻结条款。单位可以确认结束。
5. **资助中心**：异常工时核实 → 勾选仅看待核实 → 核实林同学的3小时模拟记录；正常估算由126元变201元，待核75元变0（尚未走新增工时主流程时）。
6. **管理员**：账号管理启用 pending；操作审计查看刚才的写入；匹配参数中四项合计100才可保存。
7. **学生**：为我匹配查看四项分数和覆盖时段；岗位助手输入“图书馆 A区临时岗，时薪至少20元”，查看两条当前可申请岗位与筛选依据，再打开详情自行申请。
8. **AI服务助手**：左侧打开“AI 服务助手”，可直接提问或点角色示例。试“武汉设计工程学院勤工助学一周能做几小时”“我周一下午有空，会 Excel，帮我找适合的岗位”“查看我2026-09的工时和薪酬”“帮我整理申请理由”。按回答上方模式、真实调用步骤和政策出处核验结果。对话历史按登录身份隔离。
9. **接入模型**：切换管理员 → “AI 模型配置” → 默认 DeepSeek Flash（`deepseek-flash`）→ 在本机填写 API 密钥 → 保存 → 测试连接 → 返回 AI 助手。密钥不能发到聊天。当前电脑尚无模型凭据，首次体验显示“原文与业务查询”；输入密钥后才会调用模型并显示“AI 回答”。
10. **切换服务商**：管理员模型配置可选 MiMo、阿里云百炼、OpenRouter 免费模型路由、本机 Ollama 或自定义 OpenAI 兼容服务。服务商、接口地址、模型 ID 可改；切换服务地址时需要填写对应新密钥。免费路由的实际模型、额度和可用情况可能变化。

初始工时月份是 **2026-09**。工作台固定展示该演示月；工时页可选其他自然月。今后的新增记录按实际中国日期归月，演示月之外的记录请切到对应月查看。

## 停止和复位

- 双击 **停止服务.bat**：停止本项目记录的两个Web进程及经认证、数据目录核对的专用MySQL。
- 双击 **重置演示数据.bat**，输入 `RESET`：停止本项目服务，先备份数据库到 work/backups，再恢复固定模拟数据及已核验政策。完成后双击启动体验。
- 复位仅允许本项目的本地SQLite文件或已配置的专用MySQL演示库；非demo、外部数据库或归属不符均拒绝。MySQL先保存可恢复的SQL备份再复位。重置部署日志在work/reset-log.jsonl，与业务审计分开。本次切换没有复位原数据。
- 请勿在工作台演示中同时运行自动化测试或手动编辑数据库。pytest自动使用临时隔离库。

## 常见情况

- 页面打不开：再双击启动体验；查看work/runtime/backend-error.log、frontend-error.log。
- 端口被其他应用占用：脚本会拒绝停止其他应用。请先自行关闭占用5173/8000的应用再启动。
- 看到旧页面：刷新浏览器；修改代码后先重新启动以触发构建。
- 注册后登录被拒绝：用admin_demo在账号管理启用该学生。
- 单位看不到申请：切换岗位所属单位；图书馆和实验室互相隔离。
- 工时登记被拒绝：先确认上岗；只可登记上岗日期至今天，结束后只能更正。
- 待审核无法批准：检查岗位是否满额或主动关闭。完成仍占本招聘批次名额；新一轮招聘请新建岗位。
- 政策显示没有依据：尝试自然表述、原文关键词或条款编号；换主题可点新会话，学校问题需补充已核验学校细则。
- 助手要求明确条件：工资用“时薪至少20元”或“固定岗月薪至少800元”。一次只给一个时间范围；其他表述是否生效看“理解说明”。完整排班适配请在档案填写时段，再查看规则匹配。

核心规格、数据模型、接口与测试证据在docs；官方来源与归档在data/policies。正式学校制度、10-25答辩要求和导师确认仍须另行落实。
