# 青禾 · 校园勤工助学服务原型 v0.1

根据《校园勤工助学服务智能体总计划 v1.1》实现的第一版本地体验系统。Vue 3 + Vite + Element Plus；FastAPI + SQLAlchemy。业务数据和账号均为模拟，学校规则与导师要求仍待确认。

## 直接体验

1. 双击本目录的 **启动体验.bat**。程序会启动后端和前端，并打开 http://127.0.0.1:5173。
2. 登录页选学生、用工单位、资助中心或管理员，再点击“进入我的工作台”。账号和演示密码会填好。
3. 右上角头像菜单可以切换演示身份。数据会保存，退出或刷新不会丢失。

当前电脑已安装依赖并生成前端构建；启动无需下载模型或配置数据库。后台进程不弹额外窗口，运行日志在 work/runtime。只绑定本机 127.0.0.1。

## 建议先这样试

1. **学生**：发现岗位 → 搜索“文献数字化” → 详情 → 填理由 → 提交。我的申请显示待审核。
2. **单位 / 图书馆**：申请审核 → 找林同学的新申请 → 批准 → 确认上岗。
3. **单位 / 图书馆**：工时与薪酬 → 登记工时 → 选择这条申请，日期用今天，填1.5小时。冻结时薪22元时，正常估算增加33元。
4. **学生**：工时与薪酬查看本人新增记录；“我的申请”可看冻结条款。单位可以确认结束。
5. **资助中心**：异常工时核实 → 勾选仅看待核实 → 核实林同学的3小时模拟记录；正常估算由126元变201元，待核75元变0（尚未走新增工时主流程时）。
6. **管理员**：账号管理启用 pending；操作审计查看刚才的写入；匹配参数中四项合计100才可保存。
7. **学生**：为我匹配查看四项分数和覆盖时段；政策原文查询输入“每周”，查看第21条及教育部官方出处。

初始工时月份是 **2026-09**。工作台固定展示该演示月；工时页可选其他自然月。今后的新增记录按实际中国日期归月，演示月之外的记录请切到对应月查看。

## 停止和复位

- 双击 **停止服务.bat**：只停止本项目记录、PID及启动时间匹配的两个进程。
- 双击 **重置演示数据.bat**，输入 `RESET`：停止本项目服务，先备份数据库到 work/backups，再恢复固定模拟数据及已核验政策。完成后双击启动体验。
- 复位仅允许本项目 data/campus_demo.db，其他路径、非demo环境或MySQL均拒绝重置。重置部署日志在 work/reset-log.jsonl，与业务审计分开。
- 请勿在工作台演示中同时运行自动化测试或手动编辑数据库。pytest自动使用临时隔离库。

初始全局9月值：正常45h、待核3h；正常1006元、待核75元。学生林同学：正常7h / 126元，待核3h / 75元。工资为应结算估算值，不代表发薪。

## 继续开发

后端（在 backend 目录）：

```powershell
uv sync --frozen
uv run python -m app.migrate
uv run python -m app.seed
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
uv run pytest -q
uv run ruff check app tests
```

前端（在 frontend 目录）：

```powershell
npm ci
npm run dev
npm run lint
npm run build
```

体验启动使用Vite preview提供构建文件；修改代码后启动脚本检测src更新时间并重新构建。开发中使用npm run dev热更新。API文档：http://127.0.0.1:8000/docs；启动检查：http://127.0.0.1:8000/api/ping。

.env由首次初始化生成并已忽略。MySQL需自行创建专用数据库和专用账号，将DATABASE_URL换成.env.example中的MySQL格式；然后运行迁移与种子。不要使用真实学生数据，不要复用正在演示的库运行测试。迁移0001仅负责空库建表；未来字段变更必须新增显式迁移，不依赖create_all修改旧表。

## 常见情况

- 页面打不开：再双击启动体验；查看work/runtime/backend-error.log、frontend-error.log。
- 端口被其他应用占用：脚本会拒绝停止其他应用。请先自行关闭占用5173/8000的应用再启动。
- 看到旧页面：刷新浏览器；修改代码后先重新启动以触发构建。
- 注册后登录被拒绝：用admin_demo在账号管理启用该学生。
- 单位看不到申请：切换岗位所属单位；图书馆和实验室互相隔离。
- 工时登记被拒绝：先确认上岗；只可登记上岗日期至今天，结束后只能更正。
- 待审核无法批准：检查岗位是否满额或主动关闭。完成仍占本招聘批次名额；新一轮招聘请新建岗位。
- 政策显示没有依据：尝试原文关键词或条款编号；学校问题需补充已核验学校细则。

核心规格、数据模型、接口与测试证据在docs；官方来源与归档在data/policies。正式学校制度、10-25答辩要求和导师确认仍须另行落实。
